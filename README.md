## Problem Statement

Students track spending inconsistently, sometimes losing money or getting lost in budget management. Generic planners often only focus on totals and don't provide actionable insight.

We needed a tool that:
- gives actionable feedback
- provides a weekly digest you can understand in about 10 seconds
- keeps input simple (CSV-first, CLI-friendly)
- preferably works offline so students can use it without an internet connection

## Objectives
1. Guardrails: help students stay within weekly caps
2. Learning split: help students build a habit of staying within budget envelopes
3. Fast insights: an analytical "weekly digest" that explains spending patterns
